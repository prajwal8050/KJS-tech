## 💻 Local Development

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Start development server**:
   ```bash
   npm run dev
   ```

3. **Build for production**:
   ```bash
   npm run build
   ```

## 🌐 Netlify Deployment

This project is pre-configured for instant zero-configuration deployment to [Netlify](https://www.netlify.com/):

### Option 1: Drag & Drop (Fastest)
1. Run `npm run build`
2. Open [app.netlify.com/drop](https://app.netlify.com/drop)
3. Drag and drop the `dist/` folder

### Option 2: Continuous Git Deployment
- **Build command**: `npm run build`
- **Publish directory**: `dist`
- The `public/_redirects` and `netlify.toml` files are already included for client-side routing support.
